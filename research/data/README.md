# research/data

| 檔案 | 進 repo？ | 來源 |
|---|---|---|
| `taiex_tr_monthly_raw.csv` | 是 | 證交所發行量加權股價報酬指數（含股利），逐日收盤（2003-01-02 起）。用途：第 7 節定期投入那張圖、第 8 節的表，以及第 8 節台股長線圖 2003 年以後那一段。 |
| `taiex_price_daily_1990_2002.csv` | 是 | 臺灣證券交易所「每日市場成交資訊」（`https://www.twse.com.tw/rwd/zh/afterTrading/FMTQIK?date=YYYYMM01&response=json`）逐月抓下來的**逐日**發行量加權股價指數收盤（價格，不含股利），1990-01-04～2003-01-02 共 3,588 個交易日，2026-09-22 抓取（每月一次請求、間隔 ≥1 秒）。欄位：`date`、`close`。結束在 2003-01-02 是因為那一天是含息報酬指數的第一個交易日，也就是第 8 節台股長線圖兩個口徑的接點；把接點那一天留在檔案裡，串接比例（4,524.87 ÷ 4,524.92 ＝ 0.99999）才算得出來。每一個月的月底收盤與月內最高／最低收盤都和 `taiex_price_monthend_1990_2025.csv` 逐筆對過，156 個月零不符。 |
| `shiller_sp_monthly.csv` | 是 | Robert Shiller 公開資料（耶魯）。 |
| `damodaran_histret.xls` | **否**（.gitignore 排除） | Damodaran（NYU Stern）Historical Returns on Stocks, Bonds and Bills。要重算 `asset_rotation` 的人，自己到 <https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/histretSP.html> 下載 histretSP.xls，改名成 `damodaran_histret.xls` 放在這裡。需要 `xlrd`（`pip install xlrd`）才讀得了 .xls。 |
| `sp500tr_monthend_2023_2026.csv` | 是 | S&P 500 Total Return Index（^SP500TR）各月最後一個交易日收盤，2023-01～2026-08，2026-09-22 由 Yahoo Finance 圖表 API 抓取。用途：把 Shiller 的含息月序列（股利資料止於 2023-06）用月報酬串接延長到 2026-08。口徑差異：Shiller 的價格是「當月每日收盤平均」、股利是年率÷12；SP500TR 是月底收盤、股利實際再投入。串接點（2023-06）兩邊各自的 1–6 月累積報酬相差約 0.5 個百分點（Shiller 約 10.5%、SP500TR 約 10.0%——差別主要來自平均價 vs 月底價的口徑），對 30 年年化的影響在 0.1 個百分點以內；圖說要寫明「2023 年 7 月以後用 S&P 500 總報酬指數串接」。 |
| `taiex_price_monthend_1990_2025.csv` | 是 | 臺灣證券交易所「每日市場成交資訊」（`https://www.twse.com.tw/rwd/zh/afterTrading/FMTQIK?date=YYYYMM01&response=json`）逐月抓下來，只留每月最後一個交易日的收盤，另存當月收盤最高／最低那一天，2026-09-22 抓取（共 432 個月，1990-01～2025-12）。**發行量加權股價指數，是價格指數、不含股利**（含息的報酬指數官方只從 2003 年起提供，見上面 `taiex_tr_monthly_raw.csv`）。用途：第 8 節台股長線圖的圖說要查「只看價格、不含股利的話，1990 年那個高點到哪一個月才再收在它上面」（2020-07，用月內最高收盤查；逐日那一份只到 2003-01）。圖本身畫的是 `taiex_price_daily_1990_2002.csv` 接 `taiex_tr_monthly_raw.csv` 的逐週收盤。注意：證交所線上的開高低收（`MI_5MINS_HIST`）只到 1999-01-05，所以常被引用的盤中 12,682 點查不到；本文查不到官方逐日資料，也就查不到它的確切日期，本檔與圖一律只寫收盤高點 12,495（1990-02-10 的 12,495.34）。 |
| `twse-market-dividend-yield-1994-2025.csv` | 是 | 臺灣證券交易所「市場交易月報」第 1 表「證券市場統計概要與市場總市值、投資報酬率、本益比、殖利率一覽表」（`https://www.twse.com.tw/staticFiles/inspection/inspection/02/001/YYYYMM_C02001.zip`，目錄 API `https://www.twse.com.tw/rwd/zh/statistics/download?type=02&response=json`）逐份抓下來的**全市場年底殖利率**，1994–2025 共 32 個年度，2026-09-22 抓取。欄位：`year`、`dividend_yield_pct`、`source_file`。線上最早的月報檔是 199901，該檔年度列最早到 1994，所以 1990–1993 線上查不到。**口徑警告**：官方附註寫這個殖利率的分子含「盈餘轉增資股票股利」，而配股不改變市值、加權指數已完整反映，直接拿它乘價格報酬會重複計算，要乘 0.74 折算後再用（理由與對帳見 `wip/v63-review/debate/verify-taiex-pre2003-dividends.md` 第 1.4–1.5 節）。用途：第 8 節台股長線圖圖說那一句「1990 到 2002 年那一段若也把股利算進去」。 |
| `taiex-price-vs-total-return-1990-2025.csv` | 是 | 上面那份殖利率，接上證交所發行量加權股價指數（價格）與發行量加權股價報酬指數（含息）的**年底值**，1990–2025，2026-09-22 抓取。價格取自 `https://www.twse.com.tw/rwd/zh/afterTrading/FMTQIK?date=YYYY1201&response=json`，含息取自 `https://www.twse.com.tw/rwd/zh/TAIEX/MFI94U?date=YYYY1201&response=json`（最早 92/01/02）。檔內同時放兩組近似含息序列：`*_raw_*` 是殖利率直接相乘（已知高估，不要用），`*_adj_*` 是殖利率乘 0.74 折算後相乘（本文用這一組）。1991–1993 無官方殖利率，以 2.0% 代入。用途：`tools/calc_core.py` 的 `taiex_pre2003_dividend_estimate()`，也就是第 8 節台股長線圖圖說那一句的數字來源。 |
