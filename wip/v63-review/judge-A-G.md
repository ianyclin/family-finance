### A-3 獨立查核

**(a) 審閱的例子成立。** 100 買進 → 150 → 120：從高點 150 跌 **20.0%**；對成本 100 是 **+20.0%**。兩個數字符號相反。

```
買 100 股 @100，均價 100 → 股價 150：未實現 +50.0%
再買 100 股 @150，均價 125 → 股價 150：未實現 +20.0%（沒跌，數字卻從 +50% 變 +20%）
                            → 股價 120：未實現  -4.0%，但從高點只跌 20.0%
```
定期定額每個月都會墊高加權成本，所以「未實現損益 %」**恰恰是全書唯一一把會被新錢直接污染的尺**，原文的括號說反了。這一點審閱沒說得這麼死，但成立。

**(c) 替代尺「看手上那檔股票 ETF 的股價從最近高點跌多少」的漏洞——這是本報告最重要的補充，決議表沒處理：**

1. **配息／除息（實質）。** 除息當天價格就掉。書自己在 `s8-dividend`（`guide/index.html`）寫「配出去多少，基金每一份值多少錢（淨值）就少多少」。用純股價量高點回落，等於把配息算成「跌」。台股高股息 ETF 年配率量級在 8–10%（此量級**未查證**，僅為判斷用），一年不到就能憑空吃掉「跌 10%」那一格。
2. **與全書自己的跌幅刻度不同口徑（實質，已實算）。** 我用 `research/data/taiex_tr_monthly_raw.csv`（5,666 筆日收盤）重算，完全重現書上的數字：

### G-3 再平衡速算「防守比例 × 股票漲幅 × 總資產」

**判定：成立（實質）。公式本身是對的，但只在四個沒寫出來的前提下成立，其中一個前提被讀者踩到就會差 18–56%。**

**全部出現位置（4 處，全在 `s11`）：**

| 檔案:行 | 節 id | 原文逐字 |
|---|---|---|
| `guide/index.html:2652` | `s11`（`#rebalance-head` 之後） | 「年檢那天跑出門檻，先用後面那段公式（**防守比例 × 股票當年漲幅 × 總資產**）估未來 12 個月的新錢夠不夠拉回。」 |
| `guide/index.html:2656` | `s11`（漂移圖前） | 「拉不拉得回來，看資產多大、股票漲多少（**後面那段公式**）」 |
| `guide/index.html:2732` | `s11` | 「一年投入的新錢只要達到**總資產的「防守比例 × 股票當年漲幅」**，就補得回來（八二配置、股票漲五成，約是資產的 10%；六四、股票漲三成，約是 12%）」 |
| `guide/index.html:2733` | `s11`（5/25 說明） | 「為什麼剛好是這個數：股票漲了以後總資產變大，防守那一塊要跟著長到同樣的比例，差的那一塊就是**防守比例乘漲幅乘總資產**。」 |

`lite/` 無此段。`lite/facts.txt:33` 只收 5/25 那一句，不含公式。

**獨立推導（公式為何是對的）**：期初總資產 A、股票權重 w、防守 d=1−w、股票漲 g、防守報酬 0、新錢 N 全投防守：

```
(A·d + N) / (A·w·(1+g) + A·d + N) = d
⟹ N(1−d) = A·d·w·g
⟹ N = A·d·w·g / w = A · d · g     ← 正是書上的公式
```
數值驗算：A=100、八二、漲 50% → N = 100×0.2×0.5 = **10**，補完防守 30／總 150 = 20% ✅。六四漲 30% → **12** ✅。書上兩個例子都對。

**缺的前提，以及踩到的代價（已實算）：**

| 前提 | 沒寫的後果 |
|---|---|
| **總資產＝期初**（審閱點名的） | 讀者代入年檢當下總資產：八二漲 50% → 需要 14 而非 10，**高估 40%**；八二漲 70% → 21.84 vs 14，**高估 56%**；六四漲 30% → 14.16 vs 12，**高估 18%**。方向是「以為新錢不夠，於是去賣股票」。 |
| **防守那一塊報酬＝0** | 防守放 1.7% 定存：八二漲 50% 實需 **9.66**（書上 10，高估 3.5%）。小。 |
| **起初比例正確** | 若年初就已偏離，公式完全不適用（書上沒說）。 |
| **這一年沒有按比例投入新錢**（但這正是本書的預設做法！） | 期初 100 萬、八二、股票漲 50%、每月照八二拆兩筆投 5,000：實需 **102,549**（書上公式給 100,000）；每月 20,000 → 實需 **110,197**。偏差 2.5%–10%。 |

同節 `:2651` 的舉例「股票八成、定存兩成，股票累積漲了七成，比例變成**八成七左右**」也重算過：136/156 = **87.2%** ✅。

**最小修法**：`:2652` 與 `:2732` 的「總資產」加註「期初（上次年檢那天）的總資產」，並補一句「這個速算假設防守那一塊不漲不跌、年初比例是對的；實際用當下的持有金額直接算一次更準」。`:2733` 的解釋句可照抄同一限定。

**連動檔**：這四處都不帶 `data-lite-alt`，無指紋；`lite/facts.txt` 不含；`tools/calc_core.py` 沒有這條公式（案例沒用它算過任何數字），**quotes 清單不受影響**。
