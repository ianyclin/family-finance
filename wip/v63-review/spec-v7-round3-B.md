## B1 大跌演練：把感受、應對、承受能力分開

`#drill`（完整版）與 `lite/alt/ch4-drill.html`（工作表第一張背面，第一張紙要自足）改成：

1. 算出大跌那天少多少、等於幾個月收入，念出來。（照現況，工作表版用粗估法。）
2. **我第一個反應會是什麼？** 誠實寫：＿＿＿（想賣、想停扣、想加碼、不敢看……都正常。）
3. **這個反應出現時，我事先安排好的動作是什麼？** ＿＿＿（例：關掉漲跌推播、照計畫上「市場下跌時」那一行做、想動的念頭先等＿天、打給＿＿。）
4. **做完這些安排，我覺得：**（三種回答都有下一步，沒有哪一個是「錯」）
   - □ 還是會賣，或這個損失會影響生活 → 股票比例降一成，再做一次。
   - □ 不知道 → 比例維持暫定，先用小金額；第一次真的遇到下跌時，把實際反應記下來，回來對照。
   - □ 目前覺得能照計畫做 → 寫下理由和上面的安排；比例寫暫定，以後拿實際反應來核對。
5. （完整版才有）年檢時比例掉出門檻要動防守那一步，寫得出來嗎？寫不出來就明寫「大跌時只用新錢補」。
6. 寫上日期，念給家人聽。

- 不再出現「第 2、3 步一樣／不一樣」這種比對答案的寫法；全書不出現「通過」。
- 三問第 2 題同步：「會不會恐慌賣掉？」三個選項（會／不知道／目前覺得不會）各對到演練的三個出口。
- cases 四個人的演練敘述改成同一個結構（第一反應 → 安排 → 做完安排後的判斷），**比例結果不變**（小安八成暫定、阿凱六成、小芸阿哲八成／頭期款零成、陳大哥四成），數字不動；阿凱、陳大哥「賣過」的經歷正好當「第一反應」的真實紀錄。每人壓在原字數以內。
- 一頁空白版／工作表 E 區三問那一行「（會、不知道 → 做大跌演練 □做得到）」改成和新出口一致的勾選：「（→ 做大跌演練：□降一成再做　□不知道，先小金額　□目前能照計畫做）」，放不下就縮成「（→ 做大跌演練，結果寫在 H 區）」。
- `calc_core.py` 的死字串（:234、:375）同步成新說法；quotes 盯的數字句逐字保留。

## B2 起步要求全書統一成兩個階段；完整版改成「用到才補」

**統一說法**（ten、start 節尾、firstmonth、s11 開頭、steps、s12、工作表第一張，用同一套話，不逐字也要同義）：
- 第一階段：生活安全檢查做過（沒過的先補，可以同時用不影響生活的小金額熟悉流程——小安就是這樣）＋基本理解＋六行 → 用小金額開始。
- 第二階段：金額和目標變具體了，再補需要的規劃。**必做的只有每年一次的年檢。**

**刪掉「完整版一年內補完」**，改成：「第一次年檢那天，把完整版拿出來，補當時用得到的格子。」附一張簡單對照（放 s11「你已經填了哪些」後面，四列以內，不要變成另一張必修清單）：

| 什麼時候 | 補哪裡 |
|---|---|
| 第一次年檢 | 再平衡門檻（跑掉多少才動）、多久看一次——先定規則，不要等比例跑掉才看行情決定 |
| 有了具體的目標金額和日期 | D 試算（到不到得了） |
| 已經投資的錢變多了（大約超過半年收入，是提醒不是門檻） | 完整的壓力測試與大跌演練 |
| 有家人要知道 | G 家人、家庭一頁表 |

- 「可能少多少、會不會影響生活」的基本版留在起步階段（s5 那兩張小卡），延後的只是完整計算。
- s12「這七個問題要在挑產品前先答」→ 標明：起步只需要前兩題（買什麼、怎麼買），其餘是完整版的。
- steps「第一次投資的七個步驟」裡的完整壓力測試與三問 → 標明「金額變大以後／填完整版的人」，起步的人做 s5 小卡的基本版即可。
- firstmonth「完整版 24 格不用這個月填完：一年內補完就好」→ 新說法。s11 `p.decision` 同步。
