## C. ELI5 全面檢查（兩份）
規則：specs/eli5-rules.md 的「目標」「寫法」兩節（範例區有兩個過時：收益平準金舊比喻、0050 代號段，不採用）。重點：
- 國中生讀得懂，但不讓大人覺得被當小孩；
- 先畫面、再道理、最後數字，每個數字看得出「所以呢」；
- 一句一件事、句子短、無翻譯腔、無「不是…而是…」堆疊、無空泛總結句；
- 專有名詞第一次出現就地解釋（實作版沒有名詞連結，要就地解釋或指到詞彙表）；
- 比喻不能說錯；簡化過頭的精確說法放小字；
- 正文放結論、數字、動作；推導與但書放小字；本來就好懂的不硬改；
- 完整版：重點查第一階段以後新加的內容（計畫表、欄位表、三問、壓力測試、大跌演練、另外三個人、三條路徑、四個立即停止、風險差異表、無感期、他幫我打工、台灣兩個坑、XIRR 三行、六件事、B 的新內容），舊內容抽查；
