## 方法
- Python 逐行 `re.sub(r'<[^>]+>','',line)` 去標籤後，對每行以 `re.finditer` 找關鍵詞（`起點表`、`規則卡`、`七格`、`乘 2`、`乘以 2`、`能忍幾成`、`天花板`），列出行號＋前後 30 字。

- 掃描對象只有 `guide/index.html`（1211 行），沒有掃 export/ 匯出檔與備份檔。
