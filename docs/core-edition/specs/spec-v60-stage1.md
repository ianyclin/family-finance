5. **倍數表（表二）**：改用 2% 防守後的低情境報酬率（例如 2.0／2.4／2.8／3.2／3.6／4.0%），按月複利、月底投入。
6. **他幫我打工、甜蜜點、無感期**等引用完整版的數字，以 v5.6 正式檔為準（grep 確認）。
7. **規則卡與起點表**：完整版保留「規則卡」這個詞，指計畫表的規則那幾區（F–H）；「我的投資計畫」是整張表（A–H）。s12 起點表併進計畫表（A–E），全書提到「起點表」的地方要改寫；提到「規則卡」的地方大多不用改，但要確認「七格」之類的格數說法和新計畫表對得上。

## 共同寫法規則
- 讀者國中生；正文放結論、數字、動作；推導與但書放 p.small；表格可放 details。
- 黃框作者原話不改；教學段不放商品代號（新內容一律用類別名稱）；作者黃框可以沿用現有黃框原句。
- 名詞連結每節第一次、不在 strong／黃框／白話版／標籤裡；節號連結；新名詞先加詞彙表。
- mark.key 維持 14 句（新內容不加重點句）；later、details、data-chart、story 數量變動要回報。
- 虛構人物頁首印「虛構人物，示範怎麼填，不是建議。不要抄比例，抄推理步驟。」
- 補丁格式：JSON [{"section","old","new","why"}]，old 以 **v5.6 正式檔** 為準、唯一、不跨越別人負責的節。
