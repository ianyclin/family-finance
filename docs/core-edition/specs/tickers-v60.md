# 任務一：正式檔（guide/index.html，v5.6）商品代號全掃

## 方法
- `grep -noE '0050|006208|0056|00878|009826|00692|\bVT\b|VWRA|VWRD|VALU|\bTLT\b|\bBND\b|IWDA'` 掃全檔（`guide/index.html`，1211 行）。
- 另外用寬鬆 regex `\b00[0-9]{2,5}\b`（4 位含以上、00 開頭）與 `\b[A-Z]{2,5}\b`（2–5 位大寫）對照純文字版（`guidetools.py text` 產出）交叉核對，排除誤判。
- 逐行核對是否落在 `<div class="story">`（黃框）、`<div class="data-card">`／`<p>`（教學正文）或 `<div class="source-card">`（來源連結卡）。
- **誤判排除（確定）**：`N0050001`（法規資料庫網址裡的 pcode，非 0050 ETF）在 lifecycle 節 line 1146。
- **沒掃到**：VWRD、IWDA、BND、00692 全檔查無出現（確定）。009826 只出現在 s12、products 兩節。
