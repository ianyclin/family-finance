## 寫法：先畫面，再道理，最後數字
1. 先給一個生活裡的具體例子，讓讀者腦中有畫面（網購、合唱團、班費、兩個人對比、全班平均……）。
2. 再講道理，一句只講一件事，句子短。
3. 最後才給數字，每個數字要看得出「所以呢」。
4. 專有名詞第一次出現就地用幾個字解釋（括號或同位語），不要讓讀者跳去查。
5. 能條列的比較、選項、步驟，用短條列（`<ul class="checklist">` 或原本的清單結構；不要新增 class）。
6. 比喻**不能說錯**：只用在它真的成立的範圍；簡化過頭的地方，精確說法放在下方 `p.small`。
7. 不用「不是…而是…」堆疊、不用翻譯腔、不用空泛總結句。
8. 篇幅：每節正文最多比原本長兩成；多出來的靠刪掉重複句抵銷。
9. 每節不必每段都加比喻；本來就好懂的句子不要硬改。

## 作者已看過並同意的範例（照這個密度與語氣）
- why「挑選很難贏」：想像全班考試平均 70 分。有人考 90，就一定有人考 50，全班加起來還是 70。市場也一樣：有人挑對、就有人挑錯，加起來就是市場平均。可是挑股票的人要多付「學費」（比較高的費用），扣完以後，整體就一定低於平均。所以美國的主動基金放 20 年，有 92.89% 輸給大盤。
- s11 再平衡：股票漲多了，比例就會跑掉。例如你設定股票八成、定存兩成，一年後股票漲到變九成，這時再平衡就是把它調回八成。／最省事的調法：下次存錢時，新錢先放進定存那邊，補回兩成就好，不用賣股票。／跑掉一點點不用管。常見的尺叫 5/25：差超過 5 個百分點，或超過原本比例的四分之一，兩個取比較小的那個，到了才動。例如債券設 10%，四分之一是 2.5，所以跑到 12.5% 以上或 7.5% 以下才動。
- s4 市值型：如果所有人都照「公司大小」買股票，每個人手上的比例都一樣，剛好就是整個市場，大家都拿得到。可是如果有人規定自己「只買便宜的股票」，那些貴的股票就一定要有別人接走，不可能所有人都只買便宜的。所以任何不照市值買的做法，其實都在跟別人對賭：你多買的那群贏了，就是少買的人輸了。
- s9 行為落差：基金公布的報酬，是「年初放進去就不動」的人拿到的成績。你實際賺多少，要看你什麼時候把錢放進去、什麼時候拿出來。比如基金一年漲 10%，你卻是漲到一半才大筆放錢，跌下來時又賣掉，你拿到的就可能比 10% 少很多。這個差距，叫「行為落差」。
- withdraw 報酬順序風險：兩個人退休時都有 100 萬，每年都拿一樣多的錢出來花，十年下來的平均報酬也一樣。差別只在順序：A 一退休就遇到大跌，B 是後面幾年才跌。A 在跌的時候還得賣股票付生活費，等於用低價賣掉更多；等市場漲回來，他手上的股票已經少了。所以平均一樣，A 的錢還是比較早用完。還在存錢的人剛好相反：早期下跌時，新錢反而買得比較便宜。
- sidepaths 0050：0050 裡有 50 家公司，但最大的那一家就占了一半多（約 57%）。就像一個 50 人的合唱團，有一個人的音量比其他人加起來還大：他唱走音，整首歌就走音。所以 0050 分散的是台灣其他幾十家公司，那一家沒有分散掉。
- costs 股利報稅：領到股利，報稅時有兩種算法，選對自己划算的那種：合併（股利加進薪水一起算稅，但可以用股利的 8.5% 抵稅，一戶最多抵 8 萬）；分開（股利單獨用 28% 算）。大部分上班族的稅率沒那麼高，選合併比較省；通常只有所得在最高那一級（40%）的人才選分開。報稅系統會幫你試算。另外，一次領到 2 萬元以上的股利，會先被扣 2.11% 的健保補充保費。
- s8 收益平準金：想像一個班級要分班費，原本 10 個人分。月底前突然轉來 10 個新同學，如果不處理，每個人分到的就少一半。基金的做法是：新同學加入時多交一點錢，拿來補大家的分配。所以你領到的配息裡，有一部分其實是大家交進來的錢繞一圈回來，不是基金賺的。
- steps T+2：買股票有點像網購，但付款是「下單後第二個上班日才從帳戶扣錢」，這就是 T+2。例如週一買，週三扣款，遇到假日就往後延。扣款那天錢不夠，交易不會自動取消：券商會先幫你付，再把你買的股票賣掉，賠掉的錢和費用都算你的，還會留下違約紀錄。所以買之前，先確認帳戶裡的錢夠。
- s10 損失趨避：研究估計，賠一塊錢的難受，大約要賺兩塊多的開心才抵得回來。所以帳面少了 10 萬時，那種痛會讓人特別想逃，常常就在最低點賣掉。對策是趁還沒賠錢、心情平靜時，先把「什麼情況才賣」寫在規則卡上，到時候照卡做就好。

## 你不能直接改 index.html
產出 JSON 補丁檔：陣列，每個元素 `{"section": "節 id", "old": "...", "new": "...", "why": "一句理由"}`。
- `old` 必須是 index.html 裡**逐字存在且只出現一次**的 HTML 子字串（寫完用 Python 檢查 `h.count(old)==1`）。補丁之間 `old` 不能重疊。
- 補丁寫完，在**副本**上依序套用，跑結構檢查：標籤開關成對（div p li ul ol a strong h3 h4 section figure details summary table tr td span dt dd dl mark）、`<a>` 不巢狀、href="#…" 都有對應 id。
- **數字檢查**：用 Python 抽出每節（正文＋小字，不含黃框、來源卡、figure、table）改前、改後的阿拉伯數字集合。原本的數字**一個都不能少**。新增的數字只允許是「例如」情境裡的示意數字（像「股票八成、定存兩成」「100 萬」），而且要在回報裡逐一列出、說明是示意。
